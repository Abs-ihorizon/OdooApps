Installation

  1. Install Relationship Document Map first.
  2. Copy relationship_advanced_mapping into the custom addons path.
  3. Restart Odoo, update the Apps List and install Relationship Advanced Mapping.
  4. Create document types for both related models.
  5. Create a relationship rule using a real relational field.
  6. Generate an Actions menu item or Smart Button as required.
